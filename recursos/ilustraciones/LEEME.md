# Ilustraciones de la ilustradora (18 piezas, fondo transparente)

- `hd/`     → versión grande (usar como fuente para generar los tamaños finales)
- `ligero/` → versión reducida

Sugerencia de uso por significado (orientativa; se ajusta en la pasada visual):
- corazon-latido → marca principal, bienvenida, éxito
- latido-ecg-limpio → líneas de progreso, separadores
- latido-ecg-ruido → sin conexión / error ("señal con ruido")
- caja-corazon → Beats ganados por escaneo, donaciones
- donaciones-cajas-bandera → fase Pulso
- corazon-gorro-navidad, vela-corazon → fase Empuje
- estadio-beisbol, torre-reloj, mural-*, escultura-pedestal, nubes-techo → UCV / Late Venezuela, fondos de sección
- corazon-audifonos, corazon-parlante → concierto / Late Venezuela
- figura-amarilla-corazon → perfil / estados vacíos
- ondas-espiral → carga / fondos animados
